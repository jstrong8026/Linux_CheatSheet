Linux & GIT Cheat Sheet

Linux

pwd - tells you what directory you are currently in

cd - change directory ie: cd ~/music

ls - lists the contents of the current directory

ls -l  lists the contents of the current directory and adds information (ie: file size, permissions, etc.)

more <filename>  shows the first part of a filename (ie: a text file would show howevermuch text could be displayed on the screen. Space Bar avances to show more of the file, q will quit)
